# Tavu 0.1.0 limitations

## Scope and limits

- Terminal search: MyGo v0.5.5 exposes no suitable public API for this application. There is no placeholder search button or full-scrollback polling workaround.
- Browsing every historical review round: the latest round restores; comments retain their original selected code. File/diff tabs, their preview/pinned state, scroll positions, and terminal names last only for the current run. Pinned tabs are no longer silently evicted at 16 documents.
- Inline commit drafts are isolated by project within the current app session and are not persisted across restarts. The Current Source Control composer shows the staged count; it does not add automatic staging, generated messages, or remote Git operations. Cmd+Enter submits only when the message field is focused. Failed commits preserve the draft and error details; successful submissions clear that draft.
- Terminal links accept reliable, absolute paths inside the project and can navigate to a line. Parsed columns do not yet position the cursor. Relative `file:line:column` links and permission dialogs for external paths are unavailable; unknown URL schemes are rejected.
- Open Externally uses the system's default application for the file; there is no dedicated editor selector.
- Snapshot JSON stores source text without shared content-addressed blob deduplication. Storage limits still apply.
- Current-version validation covers at most 64 relevant comparisons per refresh. Larger reviews keep their snapshots but can show an unverified version state; Tavu does not guess that versions match.
- Working-file validation checks at most 32 distinct open paths per refresh, prioritizing the active file. Selecting a working file requests another check. Timeouts and read failures produce an unavailable-check notice, not a content-change claim. Open buffers never automatically reload; use Reload Latest. Saved snapshots and historical excerpts are not reload targets.
- Quick Open performs bounded name/path lookup with at most 100 results and is separate from project text search. It is not a command palette or a persistent project-wide index.
- Search debounces typing by 180 ms and returns at most 200 individual occurrences. Regular expressions use Go syntax, one line at a time; multiline and PCRE-specific constructs are unavailable. Whole Word recognizes Unicode letters, numbers, combining marks, and `_`. Open Files Only reads current disk versions, including paths opened as historical snapshots. Large, binary, and invalid UTF-8 files are skipped and counted; errors can accompany partial results. Reaching exactly 200 matches alone does not imply truncation.
- Include/exclude filters use comma-separated project-relative globs, not `.gitignore` syntax or negation rules. A bare name matches at any depth; patterns with `/` are project-rooted unless prefixed by `**/`. Exclude Dependencies controls built-in directory exclusions; `.git` and symlink paths remain excluded when it is disabled.
- Replace writes one exact occurrence, Replace in File writes every eligible occurrence in that file, and Replace All uses an inline batch confirmation. Global Replace All refuses truncated searches and permits at most 200 eligible matches; file actions scan the complete file beyond the 200-result display limit. Source files remain limited to 2 MiB and combined old/new preview bytes to 32 MiB; the preview budget is not a total UI memory cap. Literal replacement uses text unchanged; regex replacement expands `$1`, `${name}`, and `$$`. Empty replacement deletes matches. Editors remain read-only and files are never staged automatically.
- Removing a result or file hides it from the current search and excludes it from replacement previews and writes. New queries, changed search options, and explicit Search refreshes clear these exclusions; replacement draft changes and internal refreshes retain them. Removed occurrences are tied to source hashes and rebased after local writes and undo. External edits can invalidate them, requiring a fresh search.
- Undo Replacement covers only the latest operation’s actual writes in the current project session, with one attempt and no redo or cross-restart history. It checks that content and mode still match the replacement, rejects external edits, and can report a partial restoration if a later file fails. This is an explicit undo, not automatic rollback.
- Replacement previews are immutable and may be attempted once. The backend anchors access to the project root, validates all targets before writing, and rechecks each file immediately before replacement. It refuses changed or read-only files and preserves permission/executable bits and existing CRLF line endings. Each file write is atomic; the batch has no transaction or automatic rollback. Later errors can leave partial writes, and an uncooperative external writer can still race the final check. The result reports applied files; the UI retains drafts and reports the applied count. Retrying requires a fresh preview.
- Cmd+W closes a tab in the last focused reader or terminal pane, including a focused split terminal; maximized layouts use the visible pane. It does not close the window when the workspace is empty. Running-terminal confirmation and modal guards still apply.
- Terminal Font Family keeps an explicit installed choice first. A blank value selects installed SF Mono or Menlo on macOS, with installed Symbols Nerd Font Mono or another Nerd Mono font supplying missing symbols. Tavu does not bundle or install fonts; unavailable glyphs still need a compatible installed face. The 12-point default applies to new or invalid settings, while valid saved sizes are preserved.
- New terminals remove color policy inherited from the launcher in the child environment only; shell startup files may set it again. No global force-color setting is added and existing sessions keep their environment. The new setup requires the new build and a new terminal. Color/font fixture tests do not establish compatibility with every external CLI or verify the user's actual Claude session.
- Corrupt data is backed up and reported. There is no automatic-repair or recovery dialog.
- A second application launch focuses the existing window but does not forward the new project argument. Use Open Folder in the application.
- Line/hunk staging, discard, clean, reset --hard, rebase, cherry-pick, pull/push, and worktree creation are outside this version's scope. No placeholder controls represent these actions.
- Submodule changes have limited support. Resolve merge conflicts externally. Large, binary, and non-UTF-8 files have no text reader.
- No installer DMG, Developer ID signing, notarization, or automatic updates.

## Not yet verified

- Each build has its own validation scope in [verification](verification.md). Earlier passing tests and desktop checks do not validate the latest search, replacement, shortcut, or visual changes automatically.
- Real Chinese IME candidate windows, composition, and switching between input methods. Unicode rendering and system paste do not substitute for IME testing.
- Complete workflows for every external CLI. The installed `claude --version` ran in the packaged terminal; no model request or project modification was requested.
- Long-running real-GUI RSS, leaks, and energy use during sustained output. The approximately 15 MB stress test verified completion, bounded scrollback, and headless frame response, not real-GUI memory behavior.
- Intel macOS, Linux, Windows, physical macOS 13 machines, clean user accounts, and machines without development tools.
- Distribution-time Gatekeeper behavior, certificate signing, notarization, installation locations, and other Finder environments. The local Finder checks do not establish these cases.

## Known compatibility issues and handling

1. **CLI template version mismatch.** MyGo v0.5.5 `init -template native` generated a v0.5.1 dependency. Tavu explicitly pins v0.5.5 and retains the tool declaration. No module-cache contents were changed.
2. **Executable capitalization.** The CLI derives `Tavu` from the application name without a separate executable-name field. The packaging script renames only its own output to `tavu`, updates the plist, and ad-hoc signs the resulting bundle.
3. **Host build-cache failure.** The default cache produced `package testmain: cannot find package` in testdeps. A dedicated task `GOCACHE` allowed the full tests and race suite to pass without deleting or modifying the global cache.
4. **VCS stamping before Git initialization.** Direct builds initially reported `error obtaining VCS status`. Scripts use `-buildvcs=false` for this local module, without inventing a remote or commit history. The repository was later initialized only at the user's explicit request.
5. **Unicode automation input.** Native automation's `typeText` did not deliver Chinese/emoji in this session. Actual system paste displayed them correctly. This remains an automation limitation, not a passed IME test.
6. **Unified diff line numbers.** MyGo v0.5.5's public unified DiffView uses a single line-number column. No public dual-number setting exists. Tavu retains the native renderer and offers Side by Side.
7. **Comment gutter affordance.** The restored interface uses MyGo's native hover gutter add action. Add Comment is also available in the reader toolbar. The compact comments panel and inline annotations are restored with the earlier Qoder interface.
8. **Native menu and window appearance.** Menus use NSMenu and the application requests DarkAqua. Quick Open and settings remain opaque custom dialogs. TitleBarHidden avoids MyGo's extra NSToolbar, while AppKit continues to control outer corners, shadows, and menu materials. Their exact appearance varies with the OS and accessibility settings; no custom blur strength, private window-radius API, or whole-window transparency is applied.
9. **Diff-overlay wheel handling.** Four MyGo v0.5.5 diff overlay handlers use pointer shielding that also consumes wheel input. The build adapter verifies the original source hashes, copies the pinned module into ignored `build/mygo-patch/`, and forwards wheel input to the owning editor while preserving other pointer behavior. It uses a generated module file; the original `go.mod`/`go.sum` and shared module cache remain unchanged. Use `./scripts/go.sh` for development, build, and test commands; `check.sh` and `package.sh` apply the same setup. Bare Go commands bypass the correction and can reproduce the scroll regression. A changed upstream source or unexpected patch location fails preparation instead of being patched speculatively. The bundle retains MyGo's MIT license. See [the adapter notes](../tools/mygopatch/README.md).
10. **Empty panes and process exit.** Pane visibility follows actual documents and terminal sessions. Closing the final item hides its pane and preserves split preferences; both empty panes become one workspace empty state. A shell exit leaves its output available until the terminal tab is explicitly closed. No replacement session is started by closing or focusing a pane. Opening a file or successfully creating a new terminal restores that content area.

Snapshot capture and status tokens detect common external races, but cannot prevent another process from writing immediately after a check. Git errors retain the original details. Tavu does not delete lock files that Git may leave after a timeout.
